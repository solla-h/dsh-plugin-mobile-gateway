# dsh-plugin-mobile-gateway

DeepSeek Harness용 서드파티 모바일 게이트웨이입니다. [Clarklevis1995/dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway)의 유지 관리 포크입니다.

> **권위 있는 문서:** [English](../../README.md) · [简体中文](../../README.zh-CN.md). `main` 브랜치의 문서가 최신입니다. 변경 불가능한 태그에 포함된 README는 과거 스냅샷이며 업스트림 npm 지침이 남아 있을 수 있습니다. 설치에 사용하지 마세요.

## 설치

컴패니언 앱의 표준 설치 가이드를 따르세요: [에이전트 설치 가이드](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/AGENT-SETUP.md) 또는 [사용자 가이드](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/USER-GUIDE.md). [`compatibility.json`](https://github.com/solla-h/dsh-mobile-app/blob/master/compatibility.json)에 기록된 정확한 GitHub 태그를 설치하세요. 같은 이름의 npm 패키지, `@latest`, `init`은 업스트림 배포 라인입니다. 이 포크에는 사용하지 마세요.
