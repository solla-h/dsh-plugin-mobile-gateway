# dsh-plugin-mobile-gateway

Passerelle mobile tierce pour DeepSeek Harness. Il s'agit du fork maintenu de [Clarklevis1995/dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway).

> **Documentation de référence :** [English](../../README.md) · [简体中文](../../README.zh-CN.md). La documentation de la branche `main` fait foi. Un README empaqueté dans une étiquette immuable est un instantané historique et peut encore contenir des instructions npm amont ; ne l'utilisez pas pour l'installation.

## Installation

Suivez le guide d'installation canonique de l'application compagnon : [guide d'installation pour agents](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/AGENT-SETUP.md) ou [guide utilisateur](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/USER-GUIDE.md). Installez l'étiquette GitHub exacte enregistrée dans [`compatibility.json`](https://github.com/solla-h/dsh-mobile-app/blob/master/compatibility.json). Le paquet npm de même nom, `@latest` et `init` appartiennent à la ligne de publication amont ; ne les utilisez pas pour ce fork.
