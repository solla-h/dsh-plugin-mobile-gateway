# dsh-plugin-mobile-gateway

Gateway móvil de terceros para DeepSeek Harness. Este es el fork mantenido de [Clarklevis1995/dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway).

> **Documentación autoritativa:** [English](../../README.md) · [简体中文](../../README.zh-CN.md). La documentación en `main` es la vigente. Un README empaquetado en una etiqueta inmutable es una instantánea histórica y puede contener instrucciones npm de upstream; no lo use para instalar.

## Instalación

Siga la guía canónica de la app complementaria: [guía de instalación para agentes](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/AGENT-SETUP.md) o [guía de usuario](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/USER-GUIDE.md). Instale la etiqueta exacta de GitHub registrada en [`compatibility.json`](https://github.com/solla-h/dsh-mobile-app/blob/master/compatibility.json). El paquete npm con el mismo nombre, `@latest` e `init` pertenecen a la línea de upstream; no los use para este fork.
