# dsh-plugin-mobile-gateway

Gateway móvel de terceiros para o DeepSeek Harness. Este é o fork mantido de [Clarklevis1995/dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway).

> **Documentação autoritativa:** [English](../../README.md) · [简体中文](../../README.zh-CN.md). A documentação em `main` é a vigente. Um README empacotado em uma tag imutável é um registro histórico e pode conter instruções npm do upstream; não o use para instalação.

## Instalação

Siga o guia de configuração canônico do app complementar: [guia de configuração para agentes](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/AGENT-SETUP.md) ou [guia do usuário](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/USER-GUIDE.md). Instale a tag exata do GitHub registrada em [`compatibility.json`](https://github.com/solla-h/dsh-mobile-app/blob/master/compatibility.json). O pacote npm de mesmo nome, `@latest` e `init` pertencem à linha de distribuição upstream; não os use neste fork.
