# dsh-plugin-mobile-gateway

DeepSeek Harness 向けのサードパーティ製モバイルゲートウェイです。これは [Clarklevis1995/dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway) の保守フォークです。

> **正式なドキュメント:** [English](../../README.md) · [简体中文](../../README.zh-CN.md)。`main` ブランチのドキュメントが最新です。不変タグに同梱された README は過去のスナップショットであり、上流の npm 手順が残っている場合があります。インストールには使用しないでください。

## インストール

コンパニオンアプリの正式なセットアップガイドに従ってください: [エージェント向けセットアップガイド](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/AGENT-SETUP.md) または [ユーザーガイド](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/USER-GUIDE.md)。[`compatibility.json`](https://github.com/solla-h/dsh-mobile-app/blob/master/compatibility.json) に記録された正確な GitHub タグをインストールします。同名の npm パッケージ、`@latest`、`init` は上流のリリース系統です。このフォークには使用しないでください。
