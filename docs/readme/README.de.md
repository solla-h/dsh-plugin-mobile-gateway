# dsh-plugin-mobile-gateway

Mobiles Drittanbieter-Gateway für DeepSeek Harness. Dies ist der gepflegte Fork von [Clarklevis1995/dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway).

> **Maßgebliche Dokumentation:** [English](../../README.md) · [简体中文](../../README.zh-CN.md). Die Dokumentation auf `main` ist aktuell. Eine README in einem unveränderlichen Tag ist ein historischer Stand und kann noch Upstream-npm-Anweisungen enthalten; verwenden Sie sie nicht zur Installation.

## Installation

Folgen Sie der kanonischen Einrichtung der Begleit-App: [Agent-Setup-Leitfaden](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/AGENT-SETUP.md) oder [Benutzerhandbuch](https://github.com/solla-h/dsh-mobile-app/blob/master/docs/USER-GUIDE.md). Installieren Sie genau den GitHub-Tag aus [`compatibility.json`](https://github.com/solla-h/dsh-mobile-app/blob/master/compatibility.json). Das gleichnamige npm-Paket, `@latest` und `init` gehören zur Upstream-Auslieferung und dürfen für diesen Fork nicht verwendet werden.
